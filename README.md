### 2. Тема проекта:
Система контроля и бронирования парковочных мест с автоматическим шлагбаумом.
### 3. Задачи:
* Linux (Raspberry Pi): Датчики расстояния (ультразвуковые/ИК) на каждом месте для определения занятости. Управление сервоприводом (имитация шлагбаума). Считыватель RFID/NFC меток для идентификации въезжающих.
* Сервер (Linux/FastAPI): База данных мест (свободно/занято). API для бронирования места на время. Логика открытия шлагбаума только для забронировавших.
* Android: Приложение для водителя: карта парковки в реальном времени, бронирование места, оплата (заглушка), история поездок. Режим «Администратор» для просмотра статистики загрузки.
### 4. Ожидаемый результат к декабрю 2026:
Действующий макет парковки (3-4 места) с автоматическим открытием шлагбаума по QR-коду из приложения и актуальным отображением занятости мест.
