### 2. Тема проекта:
Система контроля и бронирования парковочных мест с автоматическим шлагбаумом.
### 3. Задачи:
* Linux (Raspberry Pi): Датчики расстояния (ультразвуковые/ИК) на каждом месте для определения занятости. Управление сервоприводом (имитация шлагбаума). Считыватель RFID/NFC меток для идентификации въезжающих.
* Сервер (Linux/FastAPI): База данных мест (свободно/занято). API для бронирования места на время. Логика открытия шлагбаума только для забронировавших.
* Android: Приложение для водителя: карта парковки в реальном времени, бронирование места, оплата (заглушка), история поездок. Режим «Администратор» для просмотра статистики загрузки.
### 4. Ожидаемый результат к декабрю 2026:
Действующий макет парковки (3-4 места) с автоматическим открытием шлагбаума по QR-коду из приложения и актуальным отображением занятости мест.

## Как начать 
Сервер: Python + FastAPI
Raspberry Pi: Python + gpiozero
Android: Java + Android SDK

### 1. Клонировать репозиторий
git clone https://github.com/N1SSLA/smart-parking.git
cd smart-parking

### 2. Настроить git
git config user.name "YourName"
git config user.email "your@email"

### 3. Убедиться, что на main
git switch main
git pull

### 4. Создать ветку под свою задачу
git switch -c <тип>/<имя-задачи>

Из типов пока используем server,pi,android / future, chore (для зависимостей и инфраструктуры), test

Желательный вид веток
pi/future/openFunc
server/future/auth
android/future/...


### 5. Запустить виртуальное окружение чтобы докачивать зависимости отдельно от системы
cd .\server      ИЛИ       cd.\pi
cd .\.venv\Scripts
.\Activate.ps1 

### поставить зависимости если надо 
pip install -r requirements.txt

### Если надо запустить сервер локально! (пайплайн я настрою когда-нибудь)
Зайти в папку .\server (Обязательно в .venv)
uvicorn app.main:app --reload --port 8000
